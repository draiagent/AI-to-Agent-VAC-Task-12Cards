# 任務 03｜Agent 做財務月報

你是本任務執行 Agent，請依本卡使用已具備的工具完成工作。

目標：以已結帳資料產出可對帳的管理月報。
素材：試算表、科目對照、預算、上期資料、幣別口徑
風格：繁體中文；清楚、精簡；套用企業核准模板。
工具與必要條件：從 ERP 匯出已結帳試算表，指定借貸與損益符號規則。用 pandas 或試算表公式計算、XLSX 工具輸出。PDF 需另外使用轉檔器。
交付：管理月報 XLSX／PDF＋對帳表＋異常清單
驗收：科目完整；總額一致；幣別期間一致；財務覆核。
小型試作範圍：取兩個已結帳月份，只做收入、成本、費用與損益分析；有資料再增加資產負債及現金流。
失敗處理：未映射科目或試算表不平衡就停止定稿；期間不同不得直接比較；現金流缺資料就明列未納入。

先檢查檔案是否完整、工具能否執行及任務授權範圍。不要虛構資料、網址、執行成功或來源。缺少必要輸入時先輸出「缺口清單」及可完成的部分。與外部系統互動須按已授權範圍，這份教材本身不授權寄送、退款或正式發布。

按以下順序執行，每一步保留中間成果：
1. 鎖定口徑：確認月份、幣別、結帳狀態與分類。 使用 財務規則表；產出 口徑文件。
2. 匯入資料：取得試算表、預算與上期資料。 使用 ERP 匯出／CSV；產出 原始資料副本。
3. 檢查映射：核對借貸、重複列與科目歸類。 使用 pandas／公式；產出 資料檢核表。
4. 彙總損益：依財務核定規則計算收入成本費用。 使用 pandas／公式；產出 管理損益表。
5. 比較差異：比較預算與上期，零基期標不適用。 使用 pandas／公式；產出 差異分析表。
6. 解讀異常：引用金額與來源；原因不足列待查。 使用 AI Agent；產出 異常說明。
7. 產出月報：整合摘要、圖表、明細與對帳表。 使用 XLSX／PDF 工具；產出 月報草稿。
8. 財務覆核：總額對回原帳，確認差異說明。 使用 財務人員；產出 管理月報定稿。

若品質不通過，先修正再驗收。教學預設最多自動修正兩輪；仍失敗時停止並交付原因與中間結果。兩輪是試作設定，不是普遍最佳值。開始前由執行環境設定可接受的時間、API 成本及步數上限。

最終輸出：成果檔案、逐項 QA 結果、未完成項目、來源與版本、執行耗時。不可把草稿或未驗證方案標成核准定稿。
