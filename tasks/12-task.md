# 任務 12｜Agent 做 CEO 經營月報

你是本任務執行 Agent，請依本卡使用已具備的工具完成工作。

目標：整合核准部門資料，產出一頁摘要與三項決策議題。
素材：財務月報、業績、營運 KPI、客服摘要、策略待辦
風格：繁體中文；清楚、精簡；套用企業核准模板。
工具與必要條件：先以部門核准 CSV／XLSX 匯出作輸入；指標字典統一定義、責任人及更新時間。數據用公式計算，Agent 負責摘要與情境說明。
交付：一頁 CEO 摘要＋明細附件＋決策追蹤表
驗收：同期間同口徑；事實與推估分開；每項決策有依據。
小型試作範圍：先整合財務、業績、營運三張已核准月表；資料不足保留缺口，不強行做預測。
失敗處理：來源未核准或期間不同就標示限制；跨部門 KPI 不直接相加；情境假設須明列，不能當作已發生結果。
輸入模板：templates/12-input.csv（UTF-8 欄位骨架，填入實際資料後連同附件交付）

先檢查檔案是否完整、工具能否執行及任務授權範圍。不要虛構資料、網址、執行成功或來源。缺少必要輸入時先輸出「缺口清單」及可完成的部分。與外部系統互動須按已授權範圍，這份教材本身不授權寄送、退款或正式發布。

按以下順序執行，每一步保留中間成果：
1. 設定議題：指定本月目標與需要決策的問題。 使用 CEO／經營團隊；產出 月報任務書。
2. 整合月表：匯入核准部門數據與前次待辦。 使用 檔案／資料工具；產出 來源台帳。
3. 統一口徑：對齊期間、單位、定義與資料版本。 使用 指標字典／公式；產出 共同指標表。
4. 辨識偏差：比較目標與實績，定位重要例外。 使用 公式／AI Agent；產出 偏差清單。
5. 串聯影響：連結營收、成本、交付與客戶訊號。 使用 AI Agent；產出 經營議題。
6. 比較選項：列選項、假設、資源與預期影響。 使用 情境表／公式；產出 決策選項表。
7. 產出摘要：一頁摘要，附證據與三項決策題。 使用 AI Agent＋文件工具；產出 CEO 月報草稿。
8. 決策追蹤：記錄決議、負責人、期限與複查。 使用 CEO／任務負責人；產出 經營行動清單。

若品質不通過，先修正再驗收。教學預設最多自動修正兩輪；仍失敗時停止並交付原因與中間結果。兩輪是試作設定，不是普遍最佳值。開始前由執行環境設定可接受的時間、API 成本及步數上限。

最終輸出：成果檔案、逐項 QA 結果、未完成項目、來源與版本、執行耗時。不可把草稿或未驗證方案標成核准定稿。
