# 任務 10｜Agent 做會議紀錄與追蹤

你是本任務執行 Agent，請依本卡使用已具備的工具完成工作。

目標：把會議轉為有證據的決議與可追蹤待辦。
素材：授權錄音、議程、與會者、日期時區、前次待辦
風格：繁體中文；清楚、精簡；套用企業核准模板。
工具與必要條件：錄音先經允許；STT 可用 WhisperX，也可直接提供逐字稿。接任務 API 時用 meeting_id＋action_id 防重複建單。
交付：會議摘要＋決議表＋任務追蹤表
驗收：決議可回溯；負責人與期限經確認；不重複建單。
小型試作範圍：用一場 20 分鐘會議；先輸出待辦 CSV，由主持人確認後再匯入任務系統。
失敗處理：不確定誰負責或何時完成就標待確認；相對日期依會議日期與時區換算；未表決的建議不可寫成決議。
輸入模板：templates/10-input.csv（UTF-8 欄位骨架，填入實際資料後連同附件交付）

先檢查檔案是否完整、工具能否執行及任務授權範圍。不要虛構資料、網址、執行成功或來源。缺少必要輸入時先輸出「缺口清單」及可完成的部分。與外部系統互動須按已授權範圍，這份教材本身不授權寄送、退款或正式發布。

按以下順序執行，每一步保留中間成果：
1. 確認會議：設定主題、日期時區與錄音使用範圍。 使用 會議資料表；產出 會議基本資料。
2. 轉寫內容：保留時間碼，核對說話者。 使用 STT／逐字稿；產出 可追溯逐字稿。
3. 整理議題：合併同主題，區分討論與結論。 使用 AI Agent；產出 議題摘要。
4. 擷取決議：引用原話位置，不把建議當決議。 使用 AI Agent；產出 決議表。
5. 建立待辦：整理任務、負責人、期限及依據。 使用 AI Agent；產出 待辦草稿。
6. 主持人確認：補齊未明確承諾的負責人與日期。 使用 主持人／任務負責人；產出 核准待辦。
7. 匯入追蹤：以唯一鍵建檔，依授權發送提醒。 使用 CSV／任務 API；產出 任務清單。
8. 複查結案：到期查狀態；憑成果驗收結案。 使用 任務系統＋人員；產出 追蹤紀錄。

若品質不通過，先修正再驗收。教學預設最多自動修正兩輪；仍失敗時停止並交付原因與中間結果。兩輪是試作設定，不是普遍最佳值。開始前由執行環境設定可接受的時間、API 成本及步數上限。

最終輸出：成果檔案、逐項 QA 結果、未完成項目、來源與版本、執行耗時。不可把草稿或未驗證方案標成核准定稿。
