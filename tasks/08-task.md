# 任務 08｜Agent 做客戶開發

你是本任務執行 Agent，請依本卡使用已具備的工具完成工作。

目標：從合規取得的名單，整理優先客戶與個別開發草稿。
素材：目標客群、授權名單、公司資料、既有 CRM 紀錄
風格：繁體中文；清楚、精簡；套用企業核准模板。
工具與必要條件：CRM 匯出 CSV 即可開始；先定義分級條件與拒收名單。正式寫入需設定 CRM API、欄位映射與去重鍵。
交付：分級名單＋開發訊息草稿＋CRM 匯入檔
驗收：來源可追溯；名單去重；拒收排除；寄送另依授權。
小型試作範圍：先用 20 家已授權名單，交付 5 家優先客戶及個別訊息草稿；先不寄送。
失敗處理：聯絡方式不明就留空；資料不足不得虛構採購意圖；重複或拒收名單移出；CRM 寫入失敗保存待辦並避免重複建立。

先檢查檔案是否完整、工具能否執行及任務授權範圍。不要虛構資料、網址、執行成功或來源。缺少必要輸入時先輸出「缺口清單」及可完成的部分。與外部系統互動須按已授權範圍，這份教材本身不授權寄送、退款或正式發布。

按以下順序執行，每一步保留中間成果：
1. 定義客群：設定產業、規模、需求與排除條件。 使用 業務規則表；產出 理想客戶輪廓。
2. 取得名單：匯入已允許使用的公司與聯絡資料。 使用 CRM／授權資料；產出 來源名單。
3. 去重排除：合併重複公司，排除拒收對象。 使用 規則／表格；產出 有效名單。
4. 蒐集線索：查核公司公開需求與可用切入點。 使用 搜尋＋AI Agent；產出 客戶研究卡。
5. 評分排序：按匹配條件排序，保留分數依據。 使用 透明評分規則；產出 優先清單。
6. 撰寫草稿：連結客戶需求，提出具體價值。 使用 AI Agent；產出 個別開發訊息。
7. 檢核建檔：確認內容後依授權建立追蹤紀錄。 使用 業務主管＋CRM；產出 待執行紀錄。
8. 跟進衡量：寄送依授權；記錄回覆與下一步。 使用 CRM／業務人員；產出 商機追蹤表。

若品質不通過，先修正再驗收。教學預設最多自動修正兩輪；仍失敗時停止並交付原因與中間結果。兩輪是試作設定，不是普遍最佳值。開始前由執行環境設定可接受的時間、API 成本及步數上限。

最終輸出：成果檔案、逐項 QA 結果、未完成項目、來源與版本、執行耗時。不可把草稿或未驗證方案標成核准定稿。
