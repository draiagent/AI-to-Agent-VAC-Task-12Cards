# 任務 06｜Agent 做產品配方研究

你是本任務執行 Agent，請依本卡使用已具備的工具完成工作。

目標：提出可供研發評估的候選配方與小試計畫。
素材：產品類別、目標族群、原料規格、文獻、成本限制
風格：繁體中文；清楚、精簡；套用企業核准模板。
工具與必要條件：Agent 讀取原料規格、可得全文及試驗資料；用 PubMed/NCBI 查文獻、主管機關資料核對地區與產品類別。用公式檢查質量平衡及成本。
交付：候選配方表＋證據矩陣＋小試計畫
驗收：用量有依據；總量與單位一致；研發與品質人員覆核。
小型試作範圍：先選一種食品品類及 3–5 項原料，交付兩個研究候選方案；原料依據不足時先交資料缺口。
失敗處理：無安全性、用量或適用族群依據就不填入建議量；專利不等於有效證據；不將細胞、動物結果直接當人體功效。

先檢查檔案是否完整、工具能否執行及任務授權範圍。不要虛構資料、網址、執行成功或來源。缺少必要輸入時先輸出「缺口清單」及可完成的部分。與外部系統互動須按已授權範圍，這份教材本身不授權寄送、退款或正式發布。

按以下順序執行，每一步保留中間成果：
1. 界定產品：確認品類、族群、劑型與成本目標。 使用 研發任務書；產出 產品規格書。
2. 蒐集證據：查原料、研究與適用規範。 使用 文獻／官方資料；產出 來源清單。
3. 分級證據：區分人體、動物、細胞及供應商資料。 使用 AI Agent；產出 證據矩陣。
4. 篩選原料：比對規格、相容性與資料缺口。 使用 研發規則＋Agent；產出 候選原料表。
5. 建立候選：檢查總量、有效成分換算與成本。 使用 公式／研發條件；產出 候選配方表。
6. 審查限制：核對使用條件、標示及族群限制。 使用 研發＋品質人員；產出 審查紀錄。
7. 設計小試：定義對照、批次、量測與通過門檻。 使用 研發人員＋Agent；產出 小試計畫。
8. 實驗驗證：依實測修正配方，記錄版本與結果。 使用 研發／檢驗團隊；產出 實測與改版紀錄。

若品質不通過，先修正再驗收。教學預設最多自動修正兩輪；仍失敗時停止並交付原因與中間結果。兩輪是試作設定，不是普遍最佳值。開始前由執行環境設定可接受的時間、API 成本及步數上限。

最終輸出：成果檔案、逐項 QA 結果、未完成項目、來源與版本、執行耗時。不可把草稿或未驗證方案標成核准定稿。
