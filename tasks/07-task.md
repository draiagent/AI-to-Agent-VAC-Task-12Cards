# 任務 07｜Agent 做競品分析

你是本任務執行 Agent，請依本卡使用已具備的工具完成工作。

目標：比較 3–5 個競品，找出自家產品的定位機會。
素材：競品名單、官方頁面、價格日期、自家規格
風格：繁體中文；清楚、精簡；套用企業核准模板。
工具與必要條件：可讀取公開頁面的 Agent；表格工具；來源表。頁面不可讀可改由授權人工提供截圖，保留擷取日期。
交付：競品矩陣＋定位建議＋證據索引
驗收：同規格同通路比較；價格附日期；未知不硬填。
小型試作範圍：選三項競品與自家一項產品，統一每份或每 100 g 的價格單位。
失敗處理：不同促銷或包裝不直接比總價；未揭露資料填未知；客戶評論不可當成已驗證品質結論。
輸入模板：templates/07-input.csv（UTF-8 欄位骨架，填入實際資料後連同附件交付）

先檢查檔案是否完整、工具能否執行及任務授權範圍。不要虛構資料、網址、執行成功或來源。缺少必要輸入時先輸出「缺口清單」及可完成的部分。與外部系統互動須按已授權範圍，這份教材本身不授權寄送、退款或正式發布。

按以下順序執行，每一步保留中間成果：
1. 設定比較：選競品、客群與比較維度。 使用 AI Agent＋主管；產出 比較規格。
2. 擷取資料：記錄規格、售價、通路與日期。 使用 官方頁面／檔案；產出 原始資料表。
3. 標準換算：換成同重量、每份或同使用期間。 使用 表格公式；產出 標準化價格。
4. 整理主張：分清官方宣稱、評論與實測證據。 使用 AI Agent；產出 主張分類表。
5. 建立矩陣：以固定欄位呈現優勢與未知。 使用 表格工具；產出 競品比較表。
6. 找出差異：將差異連結到客群需求。 使用 AI Agent；產出 差異假設。
7. 設計驗證：安排客訪或訊息測試確認吸引力。 使用 行銷／產品團隊；產出 驗證計畫。
8. 核對更新：核對關鍵頁面，設定更新日期。 使用 產品主管；產出 競品分析定稿。

若品質不通過，先修正再驗收。教學預設最多自動修正兩輪；仍失敗時停止並交付原因與中間結果。兩輪是試作設定，不是普遍最佳值。開始前由執行環境設定可接受的時間、API 成本及步數上限。

最終輸出：成果檔案、逐項 QA 結果、未完成項目、來源與版本、執行耗時。不可把草稿或未驗證方案標成核准定稿。
