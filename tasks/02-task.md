# 任務 02｜Agent 做短影音

你是本任務執行 Agent，請依本卡使用已具備的工具完成工作。

目標：把授權原始素材，剪成一支 30–60 秒直式短片。
素材：原始影片、品牌素材、內容目標、授權配樂
風格：繁體中文；清楚、精簡；套用企業核准模板。
工具與必要條件：先安裝 FFmpeg/ffprobe 與可用 STT；WhisperX 是 STT 的一種。逐字對齊依語言模型可用性而定；說話者分離另需模型授權與設定。動態字幕可選 Remotion。
交付：MP4＋SRT 字幕＋剪輯清單＋QA 紀錄
驗收：字幕可讀；影音同步；全片可解碼；切點與主張正確。
小型試作範圍：提供一段 3 分鐘口播，先產出 30–60 秒、1080×1920 的直式影片。
失敗處理：轉寫不清楚的地方保留時間碼供人工確認；解碼或同步失敗回到粗剪；無影像理解能力則以抽幀與人工全片檢查補足。
輸入模板：templates/02-input.csv（UTF-8 欄位骨架，填入實際資料後連同附件交付）

先檢查檔案是否完整、工具能否執行及任務授權範圍。不要虛構資料、網址、執行成功或來源。缺少必要輸入時先輸出「缺口清單」及可完成的部分。與外部系統互動須按已授權範圍，這份教材本身不授權寄送、退款或正式發布。

按以下順序執行，每一步保留中間成果：
1. 素材解析：檢查方向、解析度、FPS、音軌、時長。 使用 ffprobe；產出 素材規格表。
2. 語音理解：轉寫並標記時間碼與不確定詞。 使用 STT（如 WhisperX）；產出 逐字稿。
3. 語意整理：辨識主線、重複、開場與行動呼籲。 使用 AI Agent；產出 內容選段表。
4. 剪輯決策：選鏡排序，建立片段與字幕時間線。 使用 AI Agent 決策引擎；產出 Timeline JSON。
5. 精準粗剪：按影格重編碼剪接，處理切點音訊。 使用 FFmpeg；產出 粗剪影片。
6. 字幕圖卡：套字幕與 Logo；靜態圖卡可用 Pillow。 使用 FFmpeg／Remotion；產出 品牌合成版。
7. 混音預覽：依輸出規格調整響度，檢查影音同步。 使用 FFmpeg＋人工預覽；產出 全片預覽。
8. QA 定稿：完整解碼；逐切點與字幕校對後定稿。 使用 ffprobe＋FFmpeg；產出 驗收成片。

若品質不通過，先修正再驗收。教學預設最多自動修正兩輪；仍失敗時停止並交付原因與中間結果。兩輪是試作設定，不是普遍最佳值。開始前由執行環境設定可接受的時間、API 成本及步數上限。

最終輸出：成果檔案、逐項 QA 結果、未完成項目、來源與版本、執行耗時。不可把草稿或未驗證方案標成核准定稿。
