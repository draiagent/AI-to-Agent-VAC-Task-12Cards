# 任務 05｜Agent 做市場研究

你是本任務執行 Agent，請依本卡使用已具備的工具完成工作。

目標：回答一個明確市場問題，產出附來源的機會評估。
素材：研究問題、地區、客群、期間、既有報告
風格：繁體中文；清楚、精簡；套用企業核准模板。
工具與必要條件：具網頁搜尋及閱讀能力的 Agent；優先政府統計、企業原始公告及研究報告。以文件或試算表保存來源與摘錄。
交付：研究摘要＋來源表＋假設與資料缺口
驗收：關鍵主張附來源日期；統計口徑一致；推估有標記。
小型試作範圍：限定一個地區、一個品類，蒐集 5–10 個可讀取的原始來源，回答三個經營問題。
失敗處理：付費牆或無全文就註明存取限制；同一新聞轉載不當多個獨立證據；找不到數據就保留缺口。
輸入模板：templates/05-input.csv（UTF-8 欄位骨架，填入實際資料後連同附件交付）

先檢查檔案是否完整、工具能否執行及任務授權範圍。不要虛構資料、網址、執行成功或來源。缺少必要輸入時先輸出「缺口清單」及可完成的部分。與外部系統互動須按已授權範圍，這份教材本身不授權寄送、退款或正式發布。

按以下順序執行，每一步保留中間成果：
1. 界定問題：指定市場、期間、客群與決策用途。 使用 AI Agent＋主管；產出 研究任務書。
2. 設計查詢：拆出需求、規模、通路與價格問題。 使用 AI Agent；產出 搜尋計畫。
3. 蒐集來源：閱讀原始資料並保留出處日期。 使用 搜尋／網頁讀取；產出 來源台帳。
4. 擷取證據：整理主張、數值、單位與適用範圍。 使用 AI Agent；產出 證據表。
5. 比對口徑：確認地區、期間、樣本及單位。 使用 表格／公式；產出 可比較資料。
6. 形成判斷：分開呈現事實、推論及未知。 使用 AI Agent；產出 研究結論。
7. 提出選項：列出機會、限制與下一步驗證。 使用 AI Agent；產出 策略選項。
8. 來源驗收：逐一開啟關鍵來源，覆核主張。 使用 研究負責人；產出 研究簡報。

若品質不通過，先修正再驗收。教學預設最多自動修正兩輪；仍失敗時停止並交付原因與中間結果。兩輪是試作設定，不是普遍最佳值。開始前由執行環境設定可接受的時間、API 成本及步數上限。

最終輸出：成果檔案、逐項 QA 結果、未完成項目、來源與版本、執行耗時。不可把草稿或未驗證方案標成核准定稿。
