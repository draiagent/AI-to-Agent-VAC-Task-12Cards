# 任務 04｜Agent 做業績分析

你是本任務執行 Agent，請依本卡使用已具備的工具完成工作。

目標：比較兩個月份的業績，提出三項有依據的改善行動。
素材：訂單明細、退貨折讓、產品成本、客戶與通路表
風格：繁體中文；清楚、精簡；套用企業核准模板。
工具與必要條件：CSV 先提供明細唯一鍵、日期、品項、數量、金額及折讓定義。以 pandas 或 SQL 聚合，再由 Agent 解讀。
交付：分析 XLSX＋圖表＋三項改善建議
驗收：淨銷售額可對帳；不重複計單；建議附證據。
小型試作範圍：以兩個月訂單分析產品及通路；成本不完整時不計毛利。
失敗處理：重複鍵、缺金額或退貨口徑不明先修正；無成本不臆測毛利；短樣本不承諾預測準確度。
輸入模板：templates/04-input.csv（UTF-8 欄位骨架，填入實際資料後連同附件交付）

先檢查檔案是否完整、工具能否執行及任務授權範圍。不要虛構資料、網址、執行成功或來源。缺少必要輸入時先輸出「缺口清單」及可完成的部分。與外部系統互動須按已授權範圍，這份教材本身不授權寄送、退款或正式發布。

按以下順序執行，每一步保留中間成果：
1. 定義指標：確認淨銷售額、訂單與毛利口徑。 使用 指標字典；產出 指標清單。
2. 清理訂單：檢查明細唯一鍵與缺漏資料。 使用 pandas／SQL；產出 乾淨明細。
3. 整合主檔：連接產品、客戶與通路分類。 使用 pandas／SQL；產出 分析資料表。
4. 彙總業績：計算淨額、客單價與可用毛利。 使用 pandas／SQL；產出 指標總表。
5. 拆解變動：定位產品、通路及客群的差異貢獻。 使用 統計計算；產出 變動貢獻表。
6. 找出線索：區分資料事實與待驗證原因。 使用 AI Agent；產出 機會與問題。
7. 提出行動：設定三項行動、負責人與追蹤指標。 使用 AI Agent；產出 行動建議表。
8. 驗收追蹤：確認數字與可行性，設定複查日。 使用 業務主管；產出 業績分析定稿。

若品質不通過，先修正再驗收。教學預設最多自動修正兩輪；仍失敗時停止並交付原因與中間結果。兩輪是試作設定，不是普遍最佳值。開始前由執行環境設定可接受的時間、API 成本及步數上限。

最終輸出：成果檔案、逐項 QA 結果、未完成項目、來源與版本、執行耗時。不可把草稿或未驗證方案標成核准定稿。
